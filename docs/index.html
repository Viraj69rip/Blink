Feature Highlights

Everything that makes Blink more than a desk ornament.

ESP32-C3 Brain

Low-cost, low-power Wi-Fi and Bluetooth 5 (LE) connectivity in a tiny footprint. Perfect for always-on desk bots.

Flutter Companion App

Send expressions, update firmware over-the-air, and monitor sensor data from a clean cross-platform mobile UI.

Motion & Touch Sensing

MPU6050 IMU detects taps, shakes, and orientation. Capacitive touch inputs bring Blink to life with physical feedback.

Technical Specs

The hardware and software stack under the hood.

Microcontroller

ESP32-C3

RISC-V single-core @ 160 MHz

Display

0.96" OLED

128×64px monochrome I²C

Motion Sensor

MPU6050

3-axis accel + 3-axis gyro

Connectivity

Wi-Fi + BLE 5

MQTT / HTTP / Bluetooth serial

Power

USB-C / 5V

Optional Li-Po charging module

Firmware

Arduino / ESP-IDF

Modular state-machine animations
